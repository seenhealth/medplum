# Mantine 8 → shadcn/ui translation guide

Apply mechanically. When a pattern is missing, port the component anyway, then add the recipe here in the same PR.

## Composition rule

Presentational props become sub-components (shadcn's `Card/CardHeader/CardContent` pattern): each part is `function Xyz({ className, ...props }: ComponentProps<'div'>)` with `data-slot="xyz"` and `cn()`; the root keeps the upstream component name and its behavior props.

```tsx
// upstream                                      // this package
<Panel width={600} fill>…</Panel>                 <Panel className="max-w-[600px] p-0">…</Panel>
<Modal opened onClose title="Edit" size="lg">     <Modal open onOpenChange={…} size="lg">
  <Stack>…</Stack>                                  <ModalHeader><ModalTitle>Edit</ModalTitle></ModalHeader>
  <Group justify="flex-end"><Button/></Group>       <ModalBody>…</ModalBody>
</Modal>                                            <ModalFooter><Button/></ModalFooter>
                                                  </Modal>
<FormSection title description withAsterisk        <FormSection outcome={outcome} errorExpression={…} htmlFor={id}>
  outcome errorExpression htmlFor>                  <FormSectionLabel required>title</FormSectionLabel>
  {children}                                        <FormSectionDescription>description</FormSectionDescription>
</FormSection>                                      {children}
                                                    <FormSectionError />
                                                  </FormSection>
<CheckboxFormSection title description htmlFor>   <CheckboxFormSection htmlFor={id}>
  <Checkbox/>                                       <Checkbox id={id}/>
</CheckboxFormSection>                              <FormSectionContent>
                                                      <FormSectionLabel>title</FormSectionLabel>
                                                      <FormSectionDescription>description</FormSectionDescription>
                                                    </FormSectionContent>
                                                  </CheckboxFormSection>
```

## Inline errors on a bare control

Upstream `<TextInput error={msg} />` with no label becomes:

```tsx
const givenError = getErrorsForInput(outcome, errorPath + '.given');
<Field data-invalid={givenError ? true : undefined} className="gap-1">
  <Input aria-invalid={givenError ? true : undefined} … />
  <FieldError>{givenError}</FieldError>
</Field>
```

`FieldError` renders nothing when its children are empty. See `human-name-input.tsx`.
