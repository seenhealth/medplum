# timeline

Upstream: `packages/react/src/Timeline/Timeline.tsx` (`TimelineItemProps extends PanelProps` / Mantine `PaperProps`). Port: a `Panel` plus a composed per-item menu.

| Upstream                                                                                       | Port                                                                                                                                                                                                                                                                            |
| ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TimelineItemProps extends PanelProps` (`PaperProps`: `p`, `m`, `shadow`, `radius`, `fill`, …) | `Omit<ComponentProps<'div'>, 'resource'>` plus `resource`, `profile`, `dateTime`, `padding`. `resource` is omitted from the HTML attribute bag so it stays a FHIR `Resource`. Style with `className` (Decision D5). `fill` is applied as `className="p-0"` on the item `Panel`. |
| `popupMenuItems?: ReactNode` (Mantine `Menu.Item` / `Menu.Dropdown` children)                  | Removed. Compose `<TimelineItemMenu>` as a child of `TimelineItem`; its children are `DropdownMenuItem`s from `@/components/ui/dropdown-menu`.                                                                                                                                  |
| `<Menu>` / `<Menu.Target>` / `<ActionIcon variant="subtle">`                                   | `DropdownMenu` / `DropdownMenuTrigger asChild` / `Button variant="ghost" size="icon"` with the same `aria-label` (`Actions for ${getReferenceString(resource)}`).                                                                                                               |
| `<ResourceAvatar size="md">`                                                                   | `ResourceAvatar` default size (`size-8`).                                                                                                                                                                                                                                       |
| `<ResourceName c="inherit" fw={500}>` / `<Text c="dimmed">`                                    | `className="font-medium text-inherit"` / `text-muted-foreground`.                                                                                                                                                                                                               |
| CSS module `.item` / `.itemPadding`                                                            | `whitespace-pre-wrap` / `px-4 pb-4`.                                                                                                                                                                                                                                            |

Behavior kept: `data-testid="timeline-item"`; author is `profile ?? resource.meta.author`; `meta.onBehalfOf` renders `on behalf of`; `dateTime` defaults to `meta.lastUpdated`.
